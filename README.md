# Curiosity Plus

Curiosity Plus is a client-side Fabric mod that adds clean, custom HUD elements to Minecraft to help you navigate and survive. The goal is to make exploration more immersive without cluttering your screen with complicated text.

## Features

* **Navigation & Time:** Keep your bearings with a boss-bar-styled compass, live `X, Y, Z` coordinates, and a world day counter.
  ![Replace this with a description](https://cdn.modrinth.com/data/cached_images/c39c872c7dc75495906a8cee9dcd271aadbd7e13_0.webp)

* **Elytra Flight Timer:** See your exact remaining flight time based on durability while soaring through the skies.
  ![Replace this with a description](https://cdn.modrinth.com/data/cached_images/29d42c2a59e28629387690c689036f8ae913d0e5_0.webp)

* **Upgraded Armor HUD:** Track your gear's durability at a glance, spot Mending enchantments easily, and see combined average armor health.

![Replace this with a description](https://cdn.modrinth.com/data/cached_images/96f90f64f921c25c382883116f564525b4eff460.png)

* **Custom Positioning:** Move the HUD widgets anywhere on your screen so they fit perfectly with your setup.

![Replace this with a description](https://cdn.modrinth.com/data/cached_images/f7c51b49f53ab9ed954dc1551622eba755aaa527.png)

* **In-Game Configuration:** Everything can be tweaked, toggled, and customized using the built-in settings menu.

## Installation

Make sure you have the Fabric Loader and Fabric API installed.

1. Download the latest version of Curiosity Plus from Modrinth.
2. Download [ukulib](https://modrinth.com/mod/ukulib) (this is required for the config menu to work).
3. Drop both `.jar` files into your Minecraft `mods` folder.
4. Launch Minecraft using your Fabric profile.
